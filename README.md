# Knock

MacBook の側面を叩くと、macOS の操作や Apple ショートカットが走るメニューバー常駐アプリです。
左右 × 1回 / 2回 / 3回タップ = 6 つのジェスチャーに、50 以上の内蔵アクションを割り当てられます。

## 動作環境

- macOS 14 以降
- Apple シリコン搭載の MacBook（内蔵加速度センサーを読み取ります）
- 検出も実行もローカル完結。外部送信は一切ありません。

## ビルドと実行

```bash
./build.sh --run
```

`dist/Knock.app` が生成され、メニューバーに常駐します。デバッグビルドは `CONFIG=debug ./build.sh`。

初回起動時にアクセシビリティの許可を求められます。キー送信とウインドウ操作に必要なので、
「システム設定 → プライバシーとセキュリティ → アクセシビリティ」で Knock を許可してください。

## 仕組み

| 層 | ファイル | 役割 |
|---|---|---|
| センサー | `Core/MotionSource.swift` | 内蔵加速度センサー（`AppleSPUHIDDevice`, Product `accel`）を IOHIDEventSystemClient 経由で読み取り |
| 検出 | `Core/TapDetector.swift` | ハイパスで重力を除去 → 立ち上がりの鋭さでノックを判定 → 左右判定 → 連続タップをまとめる |
| 実行 | `Actions/ActionRunner.swift` | キー送信 / AppleScript / Accessibility API / `shortcuts` CLI |
| 設定 | `Core/Settings.swift` | UserDefaults に即時保存 |
| UI | `UI/` | メニューバー、設定ウインドウ、実行時の HUD |

センサーはクライアントが `ReportInterval` を設定するまで停止しているため、`start()` でこれを設定してから
イベントを購読します。サンプルは g 単位で、平置き時は z 軸に重力（≈ -0.99）が乗ります。

### 誤検出を抑える仕組み

- タイピング・クリック・トラックパッド操作の直後 220ms は反応しません（設定でオフ可）
- 直近のノイズ床を追従し、静かでない環境では自動的にしきい値が上がります
- 打撃後 85ms は不応期（筐体の残響で二重に数えない）
- アプリ単位の除外リスト

## 設定項目

- **ノックマップ** — 6 スロットにアクションを割り当て。右クリックでその場で試せます
- **感度** — ライブ波形としきい値、連続タップの待ち時間、サンプリングレート（100/200/400 Hz）、左右反転
- **一般** — ログイン時起動、HUD とサウンド、権限の状態、除外アプリ

## 既知の制限

- **左右判定は要キャリブレーション**：筐体の x 軸の向きは機種で変わり得ます。左を叩いて右のアクションが
  動く場合は、設定 →「感度」→「左右の判定を入れ替える」をオンにしてください。
- **Bluetooth の切り替え**には `blueutil` が必要です（`brew install blueutil`）。未インストールの場合は
  Bluetooth 設定を開きます。macOS には非対話で切り替える公式手段がないためです。
- **ログイン時起動**は署名済みビルドでのみ確実に動作します。アドホック署名では登録に失敗することがあります。
- **ふたを閉じた状態では動作しません**（センサーの読み取りが止まるため）。
- 加速度センサーは公開 SDK に無いため、`IOHIDEventSystemClient` を実行時解決して使用しています。
  将来の macOS で使えなくなる可能性があります。センサーが読めない場合は疑似ノックのみで動作します。
